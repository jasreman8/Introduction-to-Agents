# Introduction-to-Agents
This repository explores the functionality of Generative AI agents, recognizes the key use cases of Generative agents, evaluates compositional Generative AI workflows and design patterns, and compares single-agent and multi-agent collaboration patterns. The following projects were covered while exploring and learning Generative AI agents:
 - CrewAI Agents & Components
 - LangGraph Agents & Components
 - LangGraph Compositional Workflows
 - Creating a LangGraph-based Automated Test Generation using the GenAI workflow approach.
